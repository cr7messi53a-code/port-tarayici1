# Port Tarayıcı

Ev ağındaki cihazları bulan ve açık portları sade Türkçe açıklamalarla gösteren ücretsiz Windows aracı.

## Özellikler
- Yerel ağını otomatik bulur ve canlı cihazları listeler
- Seçtiğin cihazın açık portlarını hızlı (asenkron) tarar
- Her port için risk seviyesi (Düşük / Orta / Yüksek) ve "ne yapmalı?" açıklaması
- Kurulum gerektirmez, tek `.exe`

## İndirme
[Releases](../../releases) sayfasından `PortScanner.Wpf.exe` dosyasını indir ve çalıştır.

> Windows "Bilinmeyen yayıncı" uyarısı gösterebilir. **Ek bilgi > Yine de çalıştır** seçeneğiyle açabilirsin. Uygulama açık kaynaktır, kodu bu depoda incelenebilir.

## Önemli uyarı
Bu aracı **yalnızca kendi ağında ve kendi cihazlarında** kullan. İzinsiz tarama birçok ülkede yasal sorun oluşturabilir. Sorumluluk kullanıcıya aittir.
